```text
winsploit [--catalog <path>]          launch the interactive dashboard
winsploit [--catalog <path>] list     list the tool catalog with install status
winsploit hashid <hash>...            identify hash types (+ hashcat / john modes)
winsploit --help, -h                  show help
winsploit --version, -V               show version
```

## Commands

### `winsploit`

Launches the dashboard. Needs a real interactive terminal (Windows Terminal, the console, VS Code's terminal…).

### `winsploit list`

Non-interactive: prints every tool in the catalog with its status (`installed`, `missing` or `CONFLICT`). Useful in scripts, and the quickest way to check a `tools.yaml` you've edited: every problem in the file is reported at once.

### `winsploit hashid <hash>...`

Identifies one or more hashes offline and prints the matching `hashcat -m` mode and `john --format`. See [Hash identifier](/docs/using/hashid).

## Options

| Option | Effect |
|---|---|
| `--catalog <path>` · `--catalog=<path>` | Use this `tools.yaml`. Works with or without `list` |
| `--web` | Start the [web view](/docs/web-view/overview) and open it in the browser |
| `--no-web` | Terminal only; skips the start-up question |
| `--port <n>` | Web view port (default 7878, else a free one) |
| `--lan` | Serve the web view to your local network too |

## Exit codes

`0` on success. A catalog that fails to load, or a bad flag (for example `--port` without a number between 1 and 65535), prints the problem and exits non-zero.
