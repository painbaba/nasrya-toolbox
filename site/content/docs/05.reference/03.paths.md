## Files

| What | Where |
|---|---|
| Catalog | First found of: `--catalog`, `%WINSPLOIT_CATALOG%`, next to `winsploit.exe`, the source checkout (dev builds), `%APPDATA%\winsploit\tools.yaml` |
| Settings | `%APPDATA%\winsploit\settings.yaml` |
| Run and install logs | `%LOCALAPPDATA%\winsploit\logs\<UTC timestamp>-<tool>.log` |
| Caught flags | `%LOCALAPPDATA%\winsploit\flags.txt` (or the active challenge's `flags.txt`) |
| Challenge workspaces | `%USERPROFILE%\ctf\<event>\<challenge>\`; while one is active, its `logs\` replaces the logs folder above |
| Active challenge | `%APPDATA%\winsploit\challenge.txt` (reopened at the next start) |
| Sandbox runs | `%LOCALAPPDATA%\winsploit\sandbox\<time>-<tool>\` (the `.wsb` file and the VM's `Desktop\out`) |
| Scoop apps | `<scoop root>\apps\<package>\current` (what `{scoop_app}` expands to) |

The catalog is **never** loaded from the current directory unless you pass it with `--catalog`. If one is there, the console tells you it was skipped.

## Environment variables

| Variable | Effect |
|---|---|
| `WINSPLOIT_CATALOG` | Path to the catalog to use (after `--catalog`) |
| `NO_COLOR` | Strip all colors, including backgrounds. Selections fall back to reverse video |
| `GEMINI_API_KEY`, `DEEPSEEK_API_KEY`, `OPENAI_API_KEY` | API keys for those [agent](/docs/using/agent) providers |
| `PATH`, `PATHEXT` | How tools are detected and launched. Changes made by installs are picked up live |

## How programs are found

Executables are resolved through `PATH` × `PATHEXT` and **never the current directory**, so a planted `nmap.exe` in a loot folder isn't what runs. `.cmd` and `.bat` shims (as Scoop and pipx create) are launched through Rust's escaped `cmd.exe` path.
