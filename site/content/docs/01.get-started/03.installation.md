## Requirements

| | |
|---|---|
| OS | Windows 10 or 11 (x64) |
| Package managers | [Scoop](https://scoop.sh). pipx is bootstrapped through Scoop the first time a Python tool needs it |
| To build | Rust 1.87 or newer ([rustup](https://rustup.rs)) |

## Option A: build from source

::code-group
```powershell [Build]
git clone https://github.com/tahabenissa/nasrya-toolbox
cd nasrya-toolbox
cargo build --release
.\target\release\winsploit
```

```powershell [Update]
cd nasrya-toolbox
git pull
cargo build --release
```
::

The binary is `target\release\winsploit.exe`. A dev build looks for `tools.yaml` in the source checkout, so it works from any directory.

## Option B: a release zip

Tagging `v*` publishes a Windows x64 zip (`winsploit.exe` + `tools.yaml`) on the [Releases](https://github.com/tahabenissa/nasrya-toolbox/releases) page. Unzip it anywhere and run `winsploit.exe`; the catalog next to the exe is found automatically.

::callout{type="note"}
The binary is unsigned, so Smart App Control may ask you to allow it. The current `v0.1.0` release predates most of what these docs describe, so build from source until the next tag.
::

## Where the catalog comes from

The catalog decides what `Enter` runs, so Winsploit is strict about where it reads it from. It uses the first one that exists:

1. `--catalog <path>`
2. `%WINSPLOIT_CATALOG%`
3. `tools.yaml` next to `winsploit.exe`
4. the source checkout (dev builds only)
5. `%APPDATA%\winsploit\tools.yaml`

It is **never** read from the current directory unless you pass `--catalog .\tools.yaml`. The active path is shown in the console. See the [security model](/docs/security/model) for why.

## Extra Scoop buckets

Pressing `i` adds any bucket a tool needs the first time it's needed. To add them yourself:

```powershell
scoop bucket add security https://github.com/opsqw/scoop-security    # nuclei, httpx, subfinder, katana, ffuf
scoop bucket add extras                                              # Sysinternals, jadx, Ghidra, x64dbg, …
scoop bucket add winsploit https://github.com/tahabenissa/nasrya-toolbox   # gau, john, steghide, nikto, seclists-lite
```
