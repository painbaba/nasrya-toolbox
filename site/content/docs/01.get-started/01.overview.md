Winsploit is a **native-Windows security toolbox**. It finds, installs and runs a curated catalog of :stat{k="tools"} pentest and CTF tools from one keyboard-driven terminal dashboard, or from your browser. No WSL, no VM, no guessing what actually works on Windows.

::callout{type="warning" title="Authorized use only"}
Winsploit is for authorized penetration testing, security research, CTFs and learning. Only point it at systems you own or have **explicit written permission** to test. Staying inside your rules of engagement is your responsibility.
::

## Why it exists

Kali is the home of security tooling, but plenty of people work on Windows, and the existing options all make you compromise:

| Option | What's good | What's missing |
|---|---|---|
| **Commando VM / FLARE-VM** | Excellent, thorough | One-shot *VM provisioners*, not something you open every day |
| **PentestBox** | Native and portable | Abandoned since around 2016, unclear licensing |
| **UniGetUI** | Great package GUI | No security curation, no "run the tool" workflow |
| **Winsploit** | Curated, native, installs **and** runs, MIT | Alpha |

## The three ideas

**One catalog.** Every tool is an entry in `tools.yaml`: how to detect it, how to install it, what Enter runs. Adding a tool needs no code. See [the catalog](/docs/catalog/overview).

**Install and run from the same place.** Press `i` to install through Scoop or pipx, `Enter` to run. Output streams live into one of :stat{k="slots"} terminals, and you can type into the running tool.

**Honest about Windows.** Tools are in the catalog because they run well natively. Caveats (GPU drivers, Npcap, admin) are shown on every run, and things that need Linux (live Wi-Fi capture, injection) are left out on purpose. See [compatibility](/docs/reference/compatibility).
