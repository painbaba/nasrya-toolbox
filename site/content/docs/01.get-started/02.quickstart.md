## What you need

- **Windows 10 or 11**
- [**Scoop**](https://scoop.sh): Winsploit installs tools through it
- [**Rust 1.87+**](https://rustup.rs) to build from source

## 1. Install Scoop

Skip this if `scoop --version` already works.

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression
```

## 2. Build Winsploit

```powershell
git clone https://github.com/tahabenissa/nasrya-toolbox
cd nasrya-toolbox
cargo build --release
```

## 3. Launch the dashboard

```powershell
.\target\release\winsploit
```

A development build finds the checkout's `tools.yaml` from any directory, so you can run it from wherever you like. The first launch asks whether to continue in the terminal or also open the [web view](/docs/web-view/overview), then shows a three-step tour.

## 4. Install and run a tool

1. Move to a tool with `↑` `↓`, switch category with `←` `→`, or press `/` and type to filter.
2. If it shows `○` (missing), press `i`. The install streams into the **console** (terminal 0).
3. Press `Enter`. The arguments prompt opens with an example prefilled; edit it and press `Enter` again.
4. The tool runs in its own terminal. Press `?` any time to see every key.

::callout{type="tip"}
Try `nmap` first: it's in the main Scoop bucket, and its prefilled arguments scan `scanme.nmap.org`, a host the Nmap project provides for exactly this.
::
