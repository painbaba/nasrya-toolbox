The web view is a small HTTP server built into Winsploit. It is **off by default** and designed so that opening it can't widen what Winsploit does.

## What the browser can and can't do

- It can only send the **actions the terminal's keys trigger**: run a catalog tool by name, install, stop, send a line of input, close, re-detect, identify a hash.
- It **never sends a command line**. Running a tool means "run *nmap* with these arguments", and the arguments go through the same quote-aware argv splitting as the terminal. No shell is ever involved.
- It can only download **run logs Winsploit registered** for terminals that are open. It can't read any other file.

## Local mode (default)

- Binds **127.0.0.1** only.
- **Owner sign-in:** the link printed in the terminal carries a random session token (`?t=…`). It's only accepted from a loopback address; the browser trades it for an `HttpOnly`, `SameSite=Strict` cookie and is redirected to a clean URL.
- **Every request** must address the server by IP (or `localhost`). That blocks DNS-rebinding attacks from web pages you happen to have open.
- **POSTs** must come from the page's own origin, as JSON (a CSRF guard). A page on another site can't drive your session.

## LAN mode

`W` in the dashboard, or `--lan`, serves the other machines on your network too, for a teammate or a second screen.

- Other machines connect over **HTTPS only**. A TLS handshake on the same port gets TLS; plain HTTP from the network is redirected.
- The certificate is self-signed (a LAN has no certificate authority), so browsers show a warning the first time. It's kept in `%APPDATA%\winsploit`, so its **SHA-256 fingerprint** stays the same. The terminal prints it; compare it with the one on the browser's warning page to know you're talking to the right machine.
- They become **guests**. A guest types the **one-time join key** shown in the terminal, then waits until the owner lets them in.
- The owner decides, from the terminal or the owner's page: **watch only**, **full control**, or **deny**. Only the owner manages guests and can remove them later.
- Too many wrong join keys burn the key; `L` then `n` makes a new one.

::callout{type="warning"}
Only share a session on networks you trust, and only let in people you'd hand your keyboard to: a guest with full control can run any catalog tool against any target.
::

## Turning it off

`w` stops the web view at once. Every open tab shows "Session ended", and the token and cookies stop working. A new start issues a new token.
