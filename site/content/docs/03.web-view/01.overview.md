The web view mirrors your Winsploit session in a browser tab: the catalog, every terminal streaming live, installs and hash IDs. It is **the same session**, not a second copy. The terminal stays in charge, and the browser sends back the same actions your keys trigger.

::callout{type="tip" title="Try it without installing"}
The [live demo](/demo/) runs the real web view against a simulated session in your browser. Nothing runs, and nothing leaves the tab.
::

## Start it

| How | What happens |
|---|---|
| Choose **Open in browser** at start-up | Starts the web view and opens it |
| `winsploit --web` | Same, skipping the question |
| `w` in the dashboard | Start or stop it at any time |
| `o` in the dashboard | Open it (again) in your browser |

The console prints the address. By default that's `http://127.0.0.1:7878`, or a free port if 7878 is taken (`--port` picks a fixed one). The link you open contains a one-time **session token**; your browser trades it for a cookie and the token disappears from the address bar. See [Security](/docs/web-view/security).

## What you can do

Everything the dashboard's action keys do:

- **Run** a tool in a free terminal (or pick which busy one to replace), with an arguments box and per-tool history
- **Install** a missing tool
- **Stop** a tool, **close** a terminal
- **Type into** a running tool, and end its input
- **Re-detect** installed tools
- **Identify a hash**
- **Download** a terminal's run log

Each action shows up in the terminal too, marked as started from the browser, and it's written to the run log.

## Extras in the browser

- **Grid** of all four terminals, plus a per-terminal **find** and **copy output**
- **Desktop notifications** when a tool finishes while the tab is in the background (opt-in)
- A **LAN** badge when the session is shared with your network

### The command helper

While you type a tool's arguments, a list suggests what fits: the tool's flags and subcommands (each with a one-line explanation), its [recipes](/docs/using/recipes), arguments you've used with it before, and files from the active challenge. `Ctrl+Space` opens the list at any time, `↑` `↓` choose, `Tab` or `Enter` insert. Under the box, **Explain the command** spells out what each flag in the line does. The flags come from the tool's [`options:`](/docs/catalog/tools-yaml#fields) in the catalog; both parts can be turned off in settings.

### The tool list

- **Foldable categories**: in *All* and *Installed* the tools are grouped by main category; click a group's title to fold it, or fold them all at once. Folded groups stay folded next time, and a filter always shows every match.
- The **category bar** either folds to two rows behind a "+N more" chip or stays one row that scrolls sideways (settings, *Rows*).
- **Hide the tool list** with `b` or the button left of the logo to give the terminals the whole width.
- **Descriptions** can be turned off for one line per tool.

### Resizable panels

Drag the edges between panels: the tool list's width, the tool card's height, the caught-flags panel, and the columns and rows of the grid. A focused edge also moves with the arrow keys. Double-click an edge to reset it, or use *Reset sizes* in settings.

### Colors and settings

- **Colors** (`p`, or the palette button in the top bar): pick a palette and light, dark or automatic. *Frost*, slate with an icy blue accent, is the default and matches the terminal's default theme and the logo. *Colored category titles* gives each category its own hue.
- **Settings** (`,`, or the gear): density, text size, terminal font size, line wrapping, follow new output, lines kept per terminal, confirm before closing a running tool, the command helper, the tool list and panel sizes, and notifications.

These live in the browser, not in `settings.yaml`: see [the web view's settings](/docs/reference/settings#the-web-views-settings).

## Keys in the browser

`/` filter · `↑` `↓` `j` `k` move · `←` `→` category · `Enter` run · `Ctrl+Space` suggestions · `b` tool list · `p` colors · `,` settings · `0`–`4` show a terminal · `g` grid · `f` find · `?` shortcuts. See the [keyboard reference](/docs/using/keyboard#in-the-web-view).

## When it ends

Stopping the web view with `w`, or quitting Winsploit, ends the session in every open tab. Press `o` to get a fresh link.
