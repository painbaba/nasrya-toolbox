## Command-line flags

| Flag | Effect |
|---|---|
| `--web` | Start the web view and open it in the browser (skips the start-up question) |
| `--no-web` | Terminal only (skips the start-up question) |
| `--port <n>` | Serve on port `<n>`. Default: 7878, or a free port if that's taken |
| `--lan` | Also serve your local network. See [LAN mode](/docs/web-view/security#lan-mode) |

They combine with `--catalog`:

```powershell
winsploit --web --port 9000
winsploit --catalog C:\engagements\acme\tools.yaml --web
```

## Dashboard keys

| Key | Action |
|---|---|
| `w` | Start or stop the web view |
| `W` | Start it on your LAN |
| `o` | Open it in your browser (a fresh sign-in link) |
| `L` | LAN guests: the join key, let someone in (`v` watch only, `f` full control), `x` remove, `n` new key |

## What the console prints

```text
:: web view on http://127.0.0.1:7878/?t=••••••••
:: same session as this terminal · o opens it · w stops it
```

The `?t=` part is the owner's sign-in token. The web view masks it in its own output, so a screen-shared tab doesn't leak it.
