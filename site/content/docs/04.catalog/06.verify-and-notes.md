## verify: impostor checks

Some names are taken twice. ProjectDiscovery's `httpx` and the Python library `httpx` both install an `httpx.exe`; Sysinternals `strings` and GNU `strings` both answer to `strings`. If the wrong one comes first on `PATH`, running it would be confusing at best.

```yaml
    verify: { args: "-version", contains: "projectdiscovery" }
```

At detection time Winsploit runs the `exe` it found with `args` (3-second timeout). If the output **doesn't contain** the text, the tool is shown as a **conflict** (`◐`) along with the path that won, and:

- it **won't be launched**: the console explains which program is in the way
- the fix is spelled out: press `i` to install the right one, or move its folder earlier in `PATH` (or uninstall the other program), then press `r`

## note: caveats

```yaml
    note: "Needs Npcap and an elevated terminal."
```

A `note:` is printed at the top of **every run** of that tool, so the caveat is in front of you (and in the run log) exactly when it matters. Use it for driver requirements, admin rights, GPU needs, or "use the GUI for this".

:stat{k="noted"} tools in the catalog carry a note today.
