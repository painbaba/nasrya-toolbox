:stat{k="tools"} tools across :stat{k="categories"} categories, all chosen because they run well **natively** on Windows. :stat{k="scoop"} install through Scoop and :stat{k="pipx"} through pipx; :stat{k="gui"} are desktop apps.

::callout{type="tip" title="Prefer cards?"}
The [catalog explorer](/catalog) shows the same tools as a filterable board, with each tool's install command and `tools.yaml` entry.
::

::catalog-table
::

## Legend

| Column | Meaning |
|---|---|
| **Categories** | Every category the tool is listed in, main one first |
| **Launch** | `stream` (output in a terminal), `gui` (desktop app), `web` (opens in the browser), `dataset` (files, such as wordlists). See [launch modes](/docs/catalog/launch-modes) |
| **Installs via** | Scoop bucket and package, or the pipx package |
| `verify` | The tool has an [impostor check](/docs/catalog/verify-and-notes) |
| `note` | The tool has a caveat shown on every run (hover to read it) |

## Categories

| Category | For |
|---|---|
| OSINT | people, emails, usernames, public footprint |
| Recon | subdomains, hosts, URLs and content discovery |
| Network | port scans, services, traffic and AD/SMB |
| Web | fuzzing, crawling, scanning and web vulns |
| Exploit | turn a finding into access |
| Passwords | hash identification and cracking, credentials |
| Reversing | disassemble, decompile, unpack, debug |
| Pwn | binary exploitation: ROP, exploit scripting |
| Mobile | Android apps: decompile and rebuild APKs |
| Forensics | disk, memory, metadata and file analysis |
| Crypto | encodings, ciphers, RSA and TLS |
| Stego | data hidden in images and audio |
| Wordlists | data the other tools feed on |
