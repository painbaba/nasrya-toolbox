title: Launch modes

---

`launch:` decides how `Enter` runs a tool. It defaults to `stream`.

## stream

The tool runs in one of the :stat{k="slots"} terminals. Output streams live, you can type into it, and `c` stops its whole process tree. Most of the catalog is `stream`.

## gui

Desktop apps such as Ghidra, x64dbg, dnSpy, Cutter and ZAP start **detached**, in their own window. Winsploit doesn't hold a terminal for them.

```yaml
    launch: gui
    exe: '{scoop_app}\dnSpy.exe'
    run_cmd: '{scoop_app}\dnSpy.exe'
```

## web

Starts `run_cmd` (if there is one, streamed and cancellable like `stream`), waits a moment, then opens `url` in your browser. With an empty `run_cmd` it simply opens the URL. That's how CyberChef, a single HTML page, works:

```yaml
    launch: web
    run_cmd: ''
    url: '{scoop_app}\CyberChef.html'
```

## dataset

Data such as wordlists has no `run_cmd`. `Enter` lists the files with their sizes and copies the folder path to the clipboard, ready to paste into another tool's arguments.

::callout{type="tip"}
Other tools reference a dataset with `{app:NAME}`: `-w "{app:seclists-lite}\common.txt"`. See [Placeholders](/docs/catalog/placeholders).
::
