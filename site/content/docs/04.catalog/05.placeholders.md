---
title: Placeholders
description: Point at Scoop app folders without hardcoding paths.
group: Catalog
---

| Placeholder | Expands to | Allowed in |
|---|---|---|
| `{scoop_app}` | This tool's Scoop folder: `<scoop root>\apps\<scoop>\current` | `exe`, `run_cmd`, `url` |
| `{app:NAME}` | Another installed Scoop app's folder | `exe`, `run_cmd`, `url`, `args_hint` |

## When to use them

**Apps Scoop doesn't put on PATH.** Detect and launch by full path:

```yaml
    exe: '{scoop_app}\dnSpy.exe'
    run_cmd: '{scoop_app}\dnSpy.exe'
```

**Tools that are just an HTML page:**

```yaml
    launch: web
    url: '{scoop_app}\CyberChef.html'
```

**Feeding one tool's data to another:**

```yaml
    args_hint: '-w "{app:seclists-lite}\common.txt"'
```

When you press `Enter`, the prompt shows the expanded path, so you can see exactly which file will be used.

::callout{type="important"}
Write these in `'single quotes'`. Inside double quotes YAML would turn `\c`, `\r`… into escape sequences.
::
