Select a missing tool (`○`) and press `i`. The install runs in the **console**, with the exact command shown first and its full output streamed. When it finishes, `PATH` changes are picked up live (no restart needed) and the tool turns `●`.

## Scoop (native tools)

Most tools install through [Scoop](https://scoop.sh).

- **Buckets are added for you.** If a tool lives in a bucket you haven't added yet (`extras`, `security`, `winsploit`…), Winsploit adds it first.
- **Pinned to the right bucket.** Packages are installed as `bucket/pkg`, so a same-named package in another bucket can't win.

```powershell
scoop bucket add security https://github.com/opsqw/scoop-security && scoop install security/ffuf
```

## pipx (Python tools)

Python tools (:stat{k="pipx"} of them, such as arjun, dirsearch, wfuzz, NetExec and Volatility 3) install with [pipx](https://pipx.pypa.io), so each one gets **its own virtual environment** and they can't break each other.

If pipx (or Python) is missing, Winsploit installs them through Scoop first.

## Winsploit's own bucket

Some tools aren't packaged anywhere for Windows. Winsploit ships its own Scoop bucket with :stat{k="ownBucket"} of them, each with a pinned download URL and **SHA-256 hash**. See [Winsploit's Scoop bucket](/docs/catalog/bucket).

## When an install fails

The full output is in the console and in the install's [log file](/docs/using/logs). Common causes:

| Symptom | Fix |
|---|---|
| Hash check failed | The upstream file changed. Report it; don't bypass the hash |
| A pipx tool won't build | Some packages need a C compiler; check the tool's `note:` |
| Still `○` after a successful install | Press `r` to re-detect. If the `exe` isn't on `PATH`, the catalog entry may need `{scoop_app}` |
