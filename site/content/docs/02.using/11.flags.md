Winsploit watches the output of every terminal for CTF flags. When one shows up, it is:

- **highlighted** in the output, even across wrapped lines,
- **announced** in a toast and the status line,
- **copied** to the clipboard,
- **saved** to `%LOCALAPPDATA%\winsploit\flags.txt`, or to the active [challenge](/docs/using/challenges)'s `flags.txt`, with the time, the terminal it came from and the line around it.

Each flag is caught once per session, however often it's printed again.

## What counts as a flag

**Known prefixes** from well-known platforms and events are trusted with any content: `flag{…}`, `ctf{…}`, `HTB{…}`, `THM{…}`, `picoCTF{…}`, `DUCTF{…}`, `CSAW{…}`, `uiuctf{…}`, `actf{…}`, `lactf{…}`, `idek{…}`, `SEKAI{…}`, `dice{…}`, `hkcert{…}`, `bctf{…}`, `ictf{…}`, `nite{…}`, `tjctf{…}`, `wctf{…}` and a few more. Case doesn't matter.

**Any other `WORD{…}`** that looks like a flag is reported as a *likely flag*. Its content may not contain spaces, quotes, colons, commas or braces, which keeps JSON and source code from being mistaken for flags.

**Your event's own prefix** is trusted too: set the flag format of the active [challenge](/docs/using/challenges) (`ACME` for `ACME{…}`).

## Keys

| Key | Action |
|---|---|
| `F` | List every flag caught this session, newest first |
| `↑` `↓` · `j` `k` | Move in the list |
| `Enter` · `y` | Copy the selected flag |
| `Esc` · `q` · `F` | Close the list |

## flags.txt

One tab-separated line per flag, appended across sessions:

```text
2026-11-07T18:02:11Z	strings	picoCTF{n0t_s0_h1dd3n}	... picoCTF{n0t_s0_h1dd3n} ...
```

The columns are: time (UTC), source terminal, flag, and the output line it was found in (up to 300 characters).
