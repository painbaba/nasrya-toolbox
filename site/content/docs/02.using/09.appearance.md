Press `t` for the appearance panel. Changes preview live across the whole dashboard; `Enter` saves them, `Esc` puts the old look back.

| Setting | Options |
|---|---|
| Theme | The same set as Claude Code's `/theme`: dark, light, colour-blind-friendly dark / light, ANSI-only dark / light. Plus *Winsploit classic* (the original cyan). `1`–`7` pick one directly |
| Borders | rounded `╭─╮` · plain `┌─┐` · double `╔═╗` · thick `┏━┓` · ascii `+-+` |
| Glyphs | unicode `● ○ ◐ ⠋ ▸` · ascii `* o ~ \| >` |
| Bold text | on · off |
| Overlays | docked full-width above the footer · centered |
| Backdrop | dim the dashboard behind an overlay · leave it as is |

::callout{type="tip"}
The terminal picks the typeface; these settings choose which characters Winsploit draws. If you see boxes or `?` in the Windows console, set borders and glyphs to *ascii*.
::

## settings.yaml

Saved to `%APPDATA%\winsploit\settings.yaml`. You can edit it by hand; missing keys keep their defaults. See the [settings reference](/docs/reference/settings).

```yaml
theme: dark            # light, dark-daltonized, light-daltonized, dark-ansi, light-ansi, cyan
borders: rounded       # plain, double, thick, ascii
glyphs: unicode        # ascii
bold: true
overlay: docked        # centered
backdrop: dim          # none
```

## NO_COLOR

When `NO_COLOR` is set, all colors are stripped, including backgrounds. Selection and status pills fall back to reverse video, so nothing is shown only by color.
