Winsploit runs up to :stat{k="slots"} tools at once, each in its own terminal, next to the always-open **console**.

## The console (0)

The console holds everything that isn't a tool run:

- installs (`i`), with their full Scoop or pipx output
- hash IDs (`h`)
- messages, such as which catalog was loaded or why a conflicting tool wasn't run

It can't be closed.

## Tool terminals (1–4)

- `Enter` takes the first **free** terminal: never used, or its tool has finished.
- When all four are busy, Winsploit asks which one to replace. The replaced tool is stopped and its run log is closed, so nothing is lost.
- Each terminal keeps its own output buffer, scroll position, search and input pipe.

## Switching

| Key | Action |
|---|---|
| `0`–`4` | Show that terminal |
| `Tab` | Cycle through them |
| `g` | Grid: all four tool terminals at once; `g` again for one |

A terminal with new output you haven't seen is marked in the terminal row.

## Closing

`x` closes the shown terminal. If its tool is still running, press `x` a second time to confirm. Quitting with tools still running also asks for a second `q`.
