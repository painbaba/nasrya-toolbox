The dashboard is one terminal window with everything in it. From top to bottom:

## Category row

`All · Installed · OSINT · Recon · Network · Web · Exploit · Passwords · Reversing · Pwn · Mobile · Forensics · Crypto · Stego · Wordlists`

Switch with `←` `→` (or `[` `]`). A tool can be listed in several categories; **All** groups tools under their main category, and **Installed** shows only what's on this machine. Categories nobody uses are hidden.

## Tool list

Each row shows a status glyph and the tool name:

| Glyph | Meaning |
|---|---|
| `●` | installed, ready to run |
| `○` | missing: `i` installs it |
| `◐` | **conflict**: a different program with the same name comes first on `PATH`. It won't be launched. See [verify](/docs/catalog/verify-and-notes) |

Move with `↑` `↓` (or `j` `k`). Press `/` to filter by name, category or description; words AND together, and `Esc` clears it.

## Terminals

Winsploit has the **console** (terminal 0) plus :stat{k="slots"} tool terminals.

- The **console** is always open. It holds installs, hash IDs and messages.
- Each `Enter` runs the selected tool in a **free terminal**. When all are busy, Winsploit asks which one to replace.
- `0`–`4` (or `Tab`) choose which terminal is shown; `g` shows all four at once in a grid.

See [Multiple terminals](/docs/using/terminals).

## Status line and footer

The status line says what just happened in plain words ("ffuf is not installed — press i to install it"). The footer lists the most useful keys; `?` opens the full list.

## Overlays

- `?`: every key
- `t`: [appearance](/docs/using/appearance), with live preview
- `h`: the [hash identifier](/docs/using/hashid)

Overlays dock above the footer by default (or float in the center), optionally dimming the dashboard behind them.
