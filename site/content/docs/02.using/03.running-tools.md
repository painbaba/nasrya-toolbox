## Enter, edit, Enter

Press `Enter` on an installed tool. The arguments prompt opens with the tool's `args_hint` prefilled, an example you edit rather than type from scratch. Press `Enter` again to run.

```text
nmap › -sV -T4 scanme.nmap.org
```

`↑` `↓` in the prompt cycle through arguments you've already used with that tool in this session.

## Quoting

Arguments split on spaces, and `"double"` or `'single'` quotes keep spaces together:

```text
-H "User-Agent: winsploit"     -w "C:\My Lists\big.txt"
```

- Backslashes are literal, so there's no need to double them.
- `\"` is a literal quote.
- A quoted path can't end in a backslash: write `"C:\dir"`, not `"C:\dir\"`.

Arguments are parsed into a real argv and passed straight to the program. **No shell is involved**, so `|`, `>`, `&&` and `%VAR%` are passed to the tool as text. See the [security model](/docs/security/model).

## Talking to a running tool

Every running tool gets its **own stdin pipe**, so it never fights the dashboard for keystrokes.

1. Press `s` to type a line for the shown tool, then `Enter` to send it.
2. `Ctrl+D` closes the tool's input (end of file).

Your input is echoed into the output as `> your line` and written to the [run log](/docs/using/logs).

## Stopping

`c` stops the shown tool **and every process it started** (the whole process tree, not just the parent). The output stays so you can read it; `x` closes the terminal.

## How Enter launches

What `Enter` does depends on the tool's [launch mode](/docs/catalog/launch-modes):

| Mode | Enter… |
|---|---|
| `stream` | runs it in a terminal and streams the output (most tools) |
| `gui` | starts the desktop app detached, in its own window |
| `web` | starts the server (if any), then opens its URL in your browser |
| `dataset` | lists the files and copies the folder path to the clipboard |

## Caveats and conflicts

If a tool has a [`note:`](/docs/catalog/verify-and-notes), it's printed at the top of every run (for example "needs Npcap + admin"). A tool in the `◐` conflict state is never launched; the console explains which program is in the way and how to fix it.
