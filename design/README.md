# Design choice

Chosen on 2026-11-07: **P10 Frost** palette + **L19 Iso cube** logo (dark, colored categories).

`winsploit-design-options.html` is the page they were picked from (all 10 palettes, 34 logos),
preset to this choice. Open it in a browser; it needs nothing else.

- Frost is already the web view's default palette (#93).
- The logo is not applied yet: that's the to-do below.

## The logo (L19 Iso cube)

An isometric cube with a prompt on its top face, on a 32 × 32 grid:

| Part | Path | Color |
|---|---|---|
| whole hexagon (left face shows) | `M16 2.5 28 9.3v13.4L16 29.5 4 22.7V9.3z` | darker accent |
| top face | `M16 2.5 28 9.3 16 16 4 9.3z` | lighter accent |
| right face | `M16 16 28 9.3v13.4L16 29.5z` | accent |
| prompt `>` | `M10.5 8l3 1.6-3 1.7` (stroke 1.7, round caps and joins) | text on accent |
| prompt `_` | `M15 11.5l3.2 1.8` (stroke 1.7, round caps) | text on accent |

Fixed Frost colors (for files that can't use CSS variables, like the favicon):
right face `#89C2D2`, left face `#46A0B9`, top face `#BCDDE6`, prompt `#0C191D`.
